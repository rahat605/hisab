Monthly Hisab - Supabase starter package

Read SUPABASE-SETUP.md first.
- Add your Supabase URL and publishable key to a local .env file.
- Run supabase-schema.sql in Supabase SQL Editor.
- Do not share database passwords or service_role/secret keys.

Important: this is a prepared Supabase integration scaffold, not yet a fully connected app. Existing UI still uses localStorage until the data/auth layer is migrated.
